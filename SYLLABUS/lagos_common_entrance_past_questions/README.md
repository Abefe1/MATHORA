# Lagos State Common Entrance (Model Colleges) Past Questions

Screening test for entry into Lagos State Model Colleges and upgraded junior secondary
schools (state-level Common Entrance, distinct from the Federal NCEE).

**Structure:**
- **Paper 1:** Mathematics / Quantitative Reasoning / Basic Science and Technology.
- **Paper 2:** English Studies / Verbal Reasoning / General Paper.

## Contents (4 files)

Only 2017 and 2018 were available from the source, and not every question/solution
pairing was posted:
- `LagosModelColleges_2017_Paper1_Questions.pdf` + `_Solutions.pdf`
- `LagosModelColleges_2018_Paper1_Questions.pdf` (no solutions posted)
- `LagosModelColleges_2018_Paper2_Questions.pdf` (no solutions posted)

No Paper 2 (2017) or any 2019+ files were found on the source page — this is a real
coverage gap, not a download failure.

## Provenance

Downloaded from Google Drive links published on **lasu-info.com**
([source page](https://www.lasu-info.com/2020/01/lagos-state-model-colleges-past-questions.html)),
a third-party aggregator, not the Lagos State Ministry of Education's own archive.
Same caveats as the Federal NCEE set: copyright of the underlying questions rests with
the setting body, and solutions are unverified/community-derived.
