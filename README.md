# MATHORA — Understand. Solve. Master.

> **Built from a concerned Teacher's Experience.**
> Mathora is a complete Nigerian Mathematics & Further Mathematics learning, remediation, and WAEC/BECE exam mastery system built for secondary school students, teachers, parents, and administrators.

---

## 🚀 Key Features

- **3-Step Pedagogical Engine:** Deconstruct formulas, trigger Rescue Mode remediation on mistakes, and apply WAEC/BECE exam shortcuts.
- **KaTeX Math Engine:** Step-by-step LaTeX formula rendering for algebra, quadratic equations, trigonometry, and calculus.
- **Rescue Mode Remediation:** Automated mistake analysis triggering step-by-step guidance when a student selects an incorrect answer.
- **Role-Filtered Dashboards:** Dedicated portals for **Students** (Interactive Notebook & Practice), **Teachers** (Academic Ledger & Roster), **Parents** (Calm Non-Gamified Progress Report), and **Admins** (CMS & Question Bank).
- **Theme Type Engine:** Light Mode, Dark Mode, and System Default theme support.

---

## 🛠 Tech Stack

- **Web Application (`mathora-web`):** Next.js 16 (App Router), React 19, Tailwind CSS v4, TypeScript, Framer Motion, KaTeX.
- **Mobile Application (`mathora-mobile`):** React Native, Expo Router, TypeScript.
- **Database & Schema:** PostgreSQL / Supabase RLS (`mathora_schema.sql`).

---

## 🚦 Getting Started

### Web Application (`mathora-web`)
```bash
cd mathora-web
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to launch the web platform.

### Mobile Application (`mathora-mobile`)
```bash
cd mathora-mobile
npm install
npx expo start
```
